# App demo GitHub Pages

Đây là ứng dụng web tĩnh mẫu dùng để hiểu quy trình triển khai (deploy) một ứng dụng trên GitHub.

## Quy trình

1. Code được lưu trong repository trên GitHub (`index.html`).
2. Khi push code lên nhánh `main`, GitHub Pages sẽ tự động build và host trang web.
3. Trang chạy tại: `https://<username>.github.io/<ten-repo>/`

## Chạy thử ở máy local

Mở trực tiếp file `index.html` bằng trình duyệt.
